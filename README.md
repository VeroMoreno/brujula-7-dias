# Brújula · 7 días

> Un compañero local y privado para atravesar transiciones profesionales o vitales — 7 días, 7 preguntas, ningún consejo.

## Qué es

Una pequeña aplicación local que te acompaña durante 7 días en una transición que estás viviendo: un cambio de carrera, una vuelta al trabajo, una decisión grande, un sabático, un momento de duda.

Cada día responde a una pregunta. Al séptimo día, la app lee todo lo que has escrito y te muestra **patrones** — no consejos. Tú decides qué hacer con eso.

## Principios

- 🔒 **Local-first.** Tus reflexiones nunca salen de tu ordenador.
- 📂 **Markdown como base de datos.** Tus textos son archivos `.md` que sobreviven a esta app y se pueden abrir en cualquier editor.
- 🤖 **IA con criterio.** Modelo local (Ollama) por defecto. Opcional: Claude con tu propia API key.
- 🧭 **No es terapia, no es coaching, no es gamificación.** Es un espejo estructurado.
